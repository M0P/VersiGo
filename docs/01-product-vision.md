# Product Vision

## Purpose
The software gives a private household a complete overview of its existing
insurance policies, contracts, costs, documents, and access to insurance
portals.

## Primary User Groups
- An individual with their own insurance portfolio
- A family household with shared access to selected contracts and documents
- An administrator responsible for system configuration

## Core Value
- Central capture of all insurance policies of a household
- Unified view of contract data and documents
- History of premiums and cost development per year
- Optional AI support for data extraction and benefit summaries
- Links to insurance portals
- Low operational complexity through Docker Compose deployment and the admin UI

## Product Principles
- Core functions usable offline-first without external AI
- Extensions optional and cleanly disabled by default
- Privacy first
- Family and sharing concept instead of global data access
- All settings preferably in the admin web interface instead of environment variables
