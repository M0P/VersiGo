# UI/UX

## Oberflächenprinzipien
- Dashboard-zentriert mit schneller Übersicht.
- Fokus auf Lesbarkeit komplexer Vertragsinformationen.
- Mobile-first eingeschränkt, primär Desktop-optimiert.
- Light/Dark Mode mit systemabhängiger Voreinstellung.

## Hauptbereiche
- Dashboard
- Versicherungen
- Kostenanalyse
- Dokumente
- Familie & Freigaben
- Admin

## Dashboard Widgets
- Anzahl aktiver Versicherungen
- Nächste Kündigungs- oder Verlängerungstermine
- Gesamtkosten laufendes Jahr
- Auffällige Beitragserhöhungen gegenüber Vorjahr
- Fehlende Dokumente oder unvollständige Stammdaten
- AI-Zusammenfassungen mit Statushinweisen

## Versicherungsdetailseite
- Stammdaten
- Leistungsüberblick
- Kostenhistorie als Jahresscheibe
- Dokumente
- Portal-Link(s)
- AI-Extraktion und AI-Zusammenfassung
- Freigaben
- Audit-Auszug

## Designvorschlag
- Neutrale, reduzierte Farbpalette
- Datenkarten und Tabellen mit klaren Zuständen
- Inline-Statuschips für optionale Features: `verfügbar`, `nicht konfiguriert`, `deaktiviert`, `Fehler`
